# Security Policy

## Reporting Security Issues
We take security and community safety seriously. If you discover a vulnerability or potential exploit within the dApp or associated contracts:

- **Do NOT** open a public issue.
- Please report directly to our core team:
  - **Email:** [contact.kibblesol@gmail.com](mailto:contact.kibblesol@gmail.com)
  - **Telegram:** [@kibblesol](https://t.me/kibblesol)

We will investigate and respond promptly.
