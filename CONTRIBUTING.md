# Contributing to Kibble

We welcome all contributions from the Solana and open-source community to help feed stray animals worldwide through decentralized technology.

## How to Contribute
1. **Fork the Repository**: Click "Fork" on the top right.
2. **Create a Branch**: `git checkout -b feature/your-feature-name`
3. **Make Changes**: Follow clean code standards and test your changes locally.
4. **Commit**: Use descriptive commit messages (`git commit -m 'feat: add leaderboard caching'`).
5. **Open a Pull Request**: Submit your PR targeting the `main` branch with a clear description.

## Reporting Issues & Contact
Found a bug or have a suggestion? Please open an **Issue** on GitHub, reach out via email at **contact.kibblesol@gmail.com**, or join our [Telegram Hub](https://t.me/kibblesol).
